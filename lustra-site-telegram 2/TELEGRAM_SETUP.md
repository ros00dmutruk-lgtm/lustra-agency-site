# Підключення заявок з сайту до Telegram-каналу

Код уже готовий і підключений. Залишилось 4 кроки — усе робиться в інтерфейсі Netlify, без правок коду.

## 1. Створи бота
У Telegram напиши **@BotFather** → `/newbot` → дай імʼя.
Отримаєш токен виду `123456789:AAExampleTokenHere`.

## 2. Додай бота адміністратором у свій канал
Канал → Учасники → Додати адміністратора → знайди бота → дай право «Публікація повідомлень».

## 3. Дізнайся chat_id канала
Найпростіше — перешли будь-яке повідомлення з каналу боту **@userinfobot**, він покаже `chat_id` (виглядає як `-1001234567890`).
Для публічного каналу можна замість цього використати `@назва_каналу`.

## 4. Задай змінні середовища в Netlify
Site settings → Environment variables → Add a variable:

| Key | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен з кроку 1 |
| `TELEGRAM_CHAT_ID` | chat_id або `@username` з кроку 3 |

Після збереження — **Deploys → Trigger deploy**, щоб функція підхопила нові змінні.

## Перевірка
Заповни форму на сайті (внизу сторінки або через модалку «Безкоштовний аудит») і надішли — повідомлення має прийти в канал за пару секунд.

Якщо не прийшло:
- перевір, що бот доданий у канал саме як адміністратор з правом писати;
- перевір Netlify → Functions → `telegram-notify` → Logs, там буде видно помилку;
- переконайся, що токен і chat_id скопійовані без зайвих пробілів.

## Що саме відбувається
Форма на сайті одночасно шле дані у двох напрямках:
1. У **Netlify Forms** (як і раніше — всі заявки видно в панелі Netlify).
2. У функцію `netlify/functions/telegram-notify.js`, яка форматує повідомлення і надсилає його в канал через Telegram Bot API.

Токен бота ніде не «світиться» в коді сторінки — він лежить лише на сервері (у змінних середовища Netlify), тому вкрасти його зі сторінки неможливо.
